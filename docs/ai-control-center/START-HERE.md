# AI Control Center — START HERE

This folder is the GitHub command center for AI-assisted development.

## Rule
GitHub is the command center. Chat is only a meeting room.

## Required loop
1. CTO writes or updates CURRENT_MISSION.md.
2. Codex reads CURRENT_MISSION.md before working.
3. Codex implements the mission.
4. Codex runs available tests.
5. Codex commits completed work.
6. Codex pushes to GitHub.
7. Codex updates CURRENT_STATUS.md, DAILY_REPORT.md, NEXT_ACTION.md, and BLOCKERS.md.
8. CTO reads GitHub and issues the next mission.

## Codex rule
Never stop after coding without reporting back to GitHub.

## CTO rule
Do not accept a mission as complete unless GitHub has updated status files.
